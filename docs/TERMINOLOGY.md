# Working Terminology

Names below are design vocabulary, not all final player-facing names.

| Term | Meaning |
|---|---|
| **Location** | Closed environment and its distinct rules: Hotel, Train, Estate, etc. |
| **Role** | The public job/status the character is expected to perform in the Location. |
| **Agenda** | Private objective/alignment for the run. May be innocent, adversarial, ambiguous, or unreliable. |
| **Approach** | Persistent skill-tree/playstyle family. Current candidates: Observer, Fixer, Ghost, Operator, Con Artist, Gambler. |
| **Edge** | Persistent unlocked perk within an Approach. A limited set is equipped before a run. |
| **Asset** | Temporary in-run tool, access privilege, record, relationship advantage, disguise, equipment, or other build component. |
| **Synergy** | Emergent/defined interaction between Edges, Assets, Role, Agenda, or state that meaningfully changes play. |
| **Leverage** | In-run social capital/influence used to bend situations and create opportunities. It cannot purchase truth directly. |
| **Marker** | A personal favor owed by a specific NPC; a relationship-state alternative to fungible Leverage. |
| **Suspicion** | Per-NPC belief that the player is behaving improperly or may be involved. |
| **Exposure** | Broader run-level visibility/danger generated by suspicious actions and social consensus. |
| **Stakes** | Optional difficulty modifiers selected before a run. Higher Stakes increase challenge and rewards. |
| **Milestone** | Accomplishment that can unlock specific content and may map to platform achievements. |
| **Resolution** | Location-specific run climax: dawn, final station, landing, verdict, lockdown, etc. |
| **Case File** | Authored campaign discovery/case contributing to the larger mystery. |
| **Acuity / Instinct** | Current working names for broad account mastery/progression; not locked. |
| **MVCR** | Minimum Viable Complete Run: smallest build proving start → escalation → resolution → meta reward → desire to replay. |

## Naming principles

- Prefer flavorful verbs and phrases over statistical RPG language.
- Avoid overlapping metaphors: **Stakes** is pre-run difficulty; **Exposure** is in-run danger.
- Do not create a currency unless it solves a distinct design problem.
- Persistent progression should usually unlock possibility, not raw power.
- Player-facing names should support dark humor and tension without forcing the entire game into detective/noir vocabulary.
